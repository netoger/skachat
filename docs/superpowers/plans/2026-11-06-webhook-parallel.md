# Параллельные запросы, анимация и обязательные подписки

Выбор владельца: выполнить подходящее исправление без дополнительного согласования дизайна.

Состояние, блокировка и JSON-счётчик ИИ разделяются по пользователям.
Истории и лимиты переносятся из старых файлов при первом обращении.
Один пользователь обрабатывается последовательно, разные — независимо.
Telegram получает max_connections=3. Отдельные файловые слоты ограничивают
одновременные скачивания на всём аккаунте, включая повторы webhook.
Демоны, очереди с фоновыми воркерами и планировщик не добавляются.

- [x] Проверить отрицательными тестами строгую подписку и анимацию.
- [x] Реализовать состояние и блокировки по пользователям с переносом истории и квот.
- [x] Ограничить скачивания между CGI-процессами, добавить анимацию при проверке ссылки и скачивании.
- [x] Проверить конкурентные запросы без сообщений и платного ИИ.
- [x] Выложить, обновить настройки webhook без удаления накопленных обновлений.
