# Webhook на Timeweb: план

**Цель:** обрабатывать сообщения Telegram через короткие CGI-запросы без демона.

**Архитектура:** публичный CGI-файл вызывает backend вне webroot. Backend проверяет
секретный заголовок, блокирует параллельный доступ к состоянию и использует
те же обработчики, что polling. PicklePersistence сохраняет диалоги и обработанные
update_id. Запрос подтверждается после обработки; повтор уже завершённого
update_id не вызывает обработчики повторно. Обрыв процесса между отправкой
сообщения и записью состояния всё ещё может привести к повторному ответу.

**Стек:** Python 3.10+, python-telegram-bot 21, CGI Apache, файловая блокировка Linux.

и переключение не выполняются. Постоянные процессы и планировщик не добавляются.
